# Fish Time v0.6.1

Pebble Time 2 (emery) watchface — 44 New England freshwater fish, one per day.

## Highlights

- **Full-color field-guide plates** for all 44 species (white-backed assets; no black matte on Pebble).
- **Original monochrome plates** still available via phone settings.
- **Daily rotation at midnight** is the default again (44-day cycle, no repeats within a cycle).
- **Clay settings**: color vs. B&W, optional “preview all species” (5 s) for review only.
- Cleaner common names (no “ID uncertain” in labels).

## Install

Download `fish-time-v0.6.1.pbw` from this release and open with the Pebble app, or build from source with `pebble build`.

## Assets in this release

- `fish-time-v0.6.1.pbw` — installable watchface
- `color-contact-sheet.png` — all 44 color plates
- `fish-time-emery-color.png` / `fish-time-emery-mono.png` — emulator samples
